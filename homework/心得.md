培训之前，我对 Linux 的认识很浅，只知道它是一个“命令行的操作系统”，感觉是只能用命令行操作的电脑。这次学习后，我理解到 Linux 首先是一个内核，而我们在日常使用中说的“Linux 系统”，通常是指基于 Linux 内核、再搭配各种软件和工具组成的操作系统发行版。
Linux 最核心的特点是一切皆文件和权限分明。设备、目录、配置文件在 Linux 中都以文件的形式呈现；每个文件都有所有者、所属组和其他用户的读、写、执行权限。
另外，Linux 的命令行也给我留下很深印象：每个命令只做一件事，学习 Linux 不能只背命令，更要理解我在操作哪个对象、需要什么权限、结果会写到哪里。
Ubuntu 是我接触的第一个 Linux 发行版。它基于 Debian，由 Canonical 维护，名字来自非洲祖鲁语，意思是“我为人人，人人为我”。它不是给极客炫技用的系统，而是努力降低开源技术门槛的发行版。
Ubuntu 的易用性不是没有门槛，而是把门槛放在了合理的位置——图形界面能完成大部分操作，但真正高效的工作仍然要回到终端。
Git 是我这次培训中收获最大的部分之一。以前我并未接触过git，只知道github，看到上面很厉害的项目也只能跟着B站视频操作，完全不懂这些命令是什么意思。初步学习之后再次去git项目让我有了对这些操作运行逻辑的理解。
最后就是我的一点小疑惑：视觉组是比较偏重算法的，各位前辈是如何保持创新性的，就是，如何进行算法的迭代升级，谢谢！！
